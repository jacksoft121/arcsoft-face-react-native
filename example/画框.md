# React Native VisionCamera + ArcSoft Face SDK 画框逻辑总结

本文档总结了在 React Native VisionCamera (v3/v4) 中使用 ArcSoft Face SDK 进行人脸检测并绘制跟踪框的最终解决方案。该方案已在 Android 和 iOS 真机上验证通过。

## 1. 核心问题

在竖屏 (Portrait) 模式下使用前置摄像头进行人脸检测时，面临以下坐标系转换挑战：

1.  **坐标系不一致**：
    *   **UI 坐标系**：竖屏，原点在左上角。
    *   **Camera Frame 坐标系**：
        *   **Android**：前置摄像头采集的数据通常旋转了 **270度**（逆时针），导致图像中人头向 **右**。
        *   **iOS**：前置摄像头采集的数据通常旋转了 **90度**（逆时针），导致图像中人头向 **左**。
2.  **镜像问题**：前置摄像头预览通常是镜像的，但算法处理的 Frame 数据通常是原始的。
3.  **缩放问题**：Camera Frame 的分辨率（如 1280x720）与屏幕 UI 的分辨率（如 375x812）不一致，且宽高比可能不同。

## 2. 解决方案逻辑

### 2.1 确定缩放比例 (Scale)

由于 Frame 被旋转了 90 或 270 度，其宽高 (`frameW`, `frameH`) 在映射到 UI 时需要互换。

*   **Frame 宽 (UI)** = `frameH`
*   **Frame 高 (UI)** = `frameW`

计算缩放比例以覆盖 (Cover) 屏幕：

```typescript
// viewW, viewH 为屏幕宽高
// frameW, frameH 为相机帧宽高 (例如 1280, 720)

// 注意：这里分母交换了，因为 Frame 是横着的，UI 是竖着的
const scaleX = viewW / frameH;
const scaleY = viewH / frameW;
const scale = Math.max(scaleX, scaleY); // Cover 模式

const scaledW = frameH * scale;
const scaledH = frameW * scale;

const offsetX = (viewW - scaledW) / 2;
const offsetY = (viewH - scaledH) / 2;
```

### 2.2 坐标映射公式

我们需要将算法返回的 `rect` (left, top, right, bottom) 映射到 UI 的 `x, y, w, h`。

#### Android (Head Right / 270° CCW)

*   **特征**：图像中头向右。
*   **逻辑**：需要处理 270 度旋转 + 双轴镜像（以匹配前置预览）。
*   **公式**：
    *   `x = frameH - rect.bottom`  (即 `frameH - (top + h)`)
    *   `y = frameW - rect.right`   (即 `frameW - (left + w)`)
    *   `w = rect.bottom - rect.top` (即 `h`)
    *   `h = rect.right - rect.left` (即 `w`)

#### iOS (Head Left / 90° CCW)

*   **特征**：图像中头向左。
*   **逻辑**：需要处理 90 度旋转 + X轴镜像（以匹配前置预览）。
*   **公式**：
    *   `x = frameH - rect.bottom`  (即 `frameH - (top + h)`)
    *   `y = rect.left`
    *   `w = rect.bottom - rect.top` (即 `h`)
    *   `h = rect.right - rect.left` (即 `w`)

## 3. 最终代码实现

```typescript
const reportFacesToJS = useMemo(() => {
    return Worklets.createRunOnJS((payload: { faces: FaceInfo[], frameW: number, frameH: number, imagePath?: string }) => {
        const { faces, frameW, frameH } = payload;
        
        // ... (省略部分代码)

        const viewW = cameraLayout.width;
        const viewH = cameraLayout.height;

        if (viewW === 0 || viewH === 0) return;

        if (Platform.OS === 'android') {
            // Android 逻辑
            const scaleX = viewW / frameH;
            const scaleY = viewH / frameW;
            const scale = Math.max(scaleX, scaleY);

            const scaledW = frameH * scale;
            const scaledH = frameW * scale;

            const offsetX = (viewW - scaledW) / 2;
            const offsetY = (viewH - scaledH) / 2;

            const uiBoxes = faces.map((face, i) => {
                let { left, top, right, bottom } = face.rect;

                // Android 映射公式
                const mappedLeft = frameH - bottom;
                const mappedRight = frameH - top;
                const mappedTop = frameW - right;
                const mappedBottom = frameW - left;

                const w = mappedRight - mappedLeft;
                const h = mappedBottom - mappedTop;

                return {
                    id: face.faceId || i,
                    x: mappedLeft * scale + offsetX,
                    y: mappedTop * scale + offsetY,
                    width: w * scale,
                    height: h * scale,
                    orient: face.orient,
                    color: 'red'
                };
            });
            setBoxes(uiBoxes);
        } else {
            // iOS 逻辑
            // iOS Front: 90 deg rotation (Swap W/H)
            let rotatedFrameW = frameH;
            let rotatedFrameH = frameW;

            const scaleX = viewW / rotatedFrameW;
            const scaleY = viewH / rotatedFrameH;
            const scale = Math.max(scaleX, scaleY);

            const offsetX = (viewW - rotatedFrameW * scale) / 2;
            const offsetY = (viewH - rotatedFrameH * scale) / 2;

            const uiBoxes = faces.map((face, i) => {
                let { left, top, right, bottom } = face.rect;
                let w = right - left;
                let h = bottom - top;

                // iOS 映射公式
                const x = frameH - bottom; // frameH - (top + h)
                const y = left;

                // Swap w/h
                const tmp = w;
                w = h;
                h = tmp;

                return {
                    id: face.faceId || i,
                    x: x * scale + offsetX,
                    y: y * scale + offsetY,
                    width: w * scale,
                    height: h * scale,
                    orient: face.orient,
                    color: 'red'
                };
            });
            setBoxes(uiBoxes);
        }
    });
}, [cameraLayout]);
```

## 4. 调试技巧

如果遇到方向不对，可以通过以下步骤快速定位：

1.  **截图**：使用 `saveImage` 功能保存当前 Frame。
2.  **观察图片**：看图片中人头的朝向（上、下、左、右）。
    *   **Head Right (Android)** -> 需要 270° 旋转逻辑。
    *   **Head Left (iOS)** -> 需要 90° 旋转逻辑。
3.  **推导**：
    *   **X 轴 (UI)** 通常对应 Frame 的短边 (Y轴)。
    *   **Y 轴 (UI)** 通常对应 Frame 的长边 (X轴)。
    *   根据人脸移动方向（左/右/上/下）与框移动方向的关系，确定是正比还是反比（是否需要 `Max - value`）。
